# spacii

Космос в терминале, по мотивам `asciiquarium`: звёзды с параллаксом, туманности, галактики, вращающиеся планеты с тенью, кольцами и лунами, корабли, НЛО, спутники, кометы и падающие звёзды. Каждая вселенная генерируется заново.

Каждые 15–30 секунд что-нибудь происходит: боевая станция прилетает и взрывает планету (а если планеты нет, то корабль), истребители гонятся друг за другом и стреляют, корабли уходят в гиперпространство, проплывают космический кит и медузы, летит астероидный пояс, вспыхивает сверхновая, дрейфует чёрная дыра, НЛО уносит корову. События идут колодой: пока не сыграны все, ни одно не повторяется, и одновременно их идёт не больше двух.

С версии 1.2 объекты взаимодействуют. Чёрная дыра притягивает корабли и камни, закручивает и проглатывает их. Астероид может разбить корабль, и потом прилетает буксир собирать обломки. Патруль с мигалкой гонится за лихачом: тот либо прыгает в гиперпространство, либо его берут лучом на буксир. Ракета стыкуется с орбитальной станцией и уходит. НЛО затягивает лучом астронавта и иногда роняет обратно. Две эскадры встречаются и перестреливаются. Комета бьёт в планету, и кратер светится, пока поворачивается и остывает. Корабль влетает в портал, а из другого портала выходит он же, он же задом наперёд или корова. Звено истребителей проходит по жёлобу боевой станции и пускает торпеду. Машина разгоняется и исчезает во вспышке, оставив две огненные полосы. Автостопщика с полотенцем подбирает грузовик. Силуэт велосипеда пересекает луну. Кит и горшок с петуниями падают сверху. Чёрный монолит проходит над планетой, и в момент выравнивания вспыхивает линия. Кит глотает зонды, медузы разлетаются от кораблей, астронавт машет пролетающим.

Среди обычных прохожих теперь синяя будка, которая кувыркается, тарелка с гондолами, летающее блюдце на леске, кот в коробке (иногда коробка пуста), зонд-дроид, солнечный парус, радиотарелка, грузовой поезд из контейнеров, патрульный катер и корова. Изредка попадаются чайник и красный автомобиль.

Один файл на Python 3.8+, без зависимостей.

## Установка (macOS, Linux)

```sh
curl -fsSL https://raw.githubusercontent.com/Olegg000/spacii/main/install.sh | sh
```

Потом:

```sh
spacii
```

Скрипт кладёт `spacii` в `~/.local/bin` и, если этой папки нет в `PATH`, дописывает её в `~/.zshrc`. На macOS нужен `python3`: он ставится командой `xcode-select --install` или уже есть вместе с Homebrew.

Без установки:

```sh
python3 <(curl -fsSL https://raw.githubusercontent.com/Olegg000/spacii/main/spacii)
```

Удалить:

```sh
curl -fsSL https://raw.githubusercontent.com/Olegg000/spacii/main/install.sh | sh -s -- --uninstall
```

## Клавиши

| Клавиша | Действие |
| --- | --- |
| `q` | выход |
| `p` или пробел | пауза |
| `r` | новая вселенная |
| `c` | корабли и события вкл/выкл |
| `e` | следующее событие сразу |

## Параметры

| Параметр | Что делает |
| --- | --- |
| `-c`, `--calm` | без кораблей, только космос |
| `-t`, `--transparent` | не заливать фон чёрным |
| `-f N`, `--fps N` | кадров в секунду, по умолчанию 20 |
| `-s N`, `--seed N` | одна и та же вселенная каждый раз |
| `--snapshot N` | напечатать один кадр после N шагов и выйти |

Лучше всего выглядит в терминале с 256 цветами и на большом окне.
